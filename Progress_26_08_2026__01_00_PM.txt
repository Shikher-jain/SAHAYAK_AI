 1. PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Description : Full-stack AI learning platform with Multimodal RAG,
                JWT Authentication, Conversational Memory, and Multilingual Support.

  Tech Stack  :
    • Backend    → FastAPI + SQLAlchemy + Python 3.11
    • Frontend   → Streamlit (single-page app, 917 lines)
    • Vector DB  → Qdrant (primary) + FAISS (fallback)
    • Embeddings → sentence-transformers/all-MiniLM-L6-v2 (384-dim)
    • LLMs       → Groq (Llama 3.1 8B) → OpenAI → HuggingFace (fallback chain)
    • Auth       → JWT + bcrypt + OAuth2 + SQLAlchemy (SQLite/Postgres)
    • Memory     → LangChain ConversationBufferWindowMemory (5-turn)
    • Deployment → Docker Compose + Render (render.yaml)

  License     : MIT

 11. ARCHITECTURE STRENGTHS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✅ Multi-tier fallback design: Every AI component has graceful degradation
     (Groq → OpenAI → HF API → Local model → Keyword fallback).

  ✅ Vector DB fallback: Qdrant (cloud) → FAISS (local) — the app runs
     anywhere, even without a cloud Qdrant cluster.

  ✅ Lazy imports: Heavy ML libraries (torch, transformers, whisper) are
     loaded only when actually needed, preventing unnecessary RAM usage.

  ✅ ENABLE_LOCAL_ML_MODELS gate: Prevents OOM on low-RAM hosts (Render free
     tier, 512MB) by keeping heavy models off by default.

  ✅ SSRF protection: URL ingestion validates against private IPs, loopback,
     and local network addresses before fetching.

  ✅ Security best practices: JWT_SECRET_KEY enforced at startup (no insecure
     default), SHA256 pre-hash for bcrypt, no wildcard CORS.

  ✅ Clean separation of concerns: Routers → Services → Ingestion → Common,
     with centralized path management via data_paths.py.

  ✅ Comprehensive multimodal support: 8 content types + batch upload,
     all auto-routed by file extension.
